
Este projeto foi desenvolvido para a empresa fictícia Alfatec, especializada na criação de softwares para clínicas veterinárias.

O sistema possui duas aplicações separadas:

alfatec-main
software

Ambas precisam ser instaladas e executadas individualmente.

 Como Executar o Projeto
1️. Clonar o repositório
git clone <URL_DO_REPOSITORIO>
📂 Executando a pasta alfatec-main
Entrar na pasta
cd alfatec-main
Instalar as dependências
npm install
Iniciar o projeto
npm run dev
📂 Executando a pasta software
Entrar na pasta
cd software
Instalar as dependências
npm install
Iniciar o projeto
npm run dev
Arquivo .env

O arquivo .env não está disponível no repositório do GitHub, pois contém informações sensíveis e configurações importantes para o funcionamento do sistema.

Para executar corretamente o projeto, é necessário baixar ou solicitar o arquivo .env separadamente e adicioná-lo nas pastas correspondentes do projeto.
